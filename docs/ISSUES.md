# 问题记录

此文档记录审查中发现的问题。修复后保留原问题并加删除线，紧接着写明修复和验证；尚未处理的条目不划掉。

## 2026-09-24 · Phase 3 审查

### 1. 会话文件载入失败会破坏当前界面 · 已修复

~~导入的会话若包含不能重放的命令，界面会先替换当前会话，然后报错；后续读取状态仍会报错。文件选择器也没有向用户展示载入错误。~~

修复：先检查会话与想定是否匹配、节点与分支结构、编号计数及重做链是否有效，并重放所有节点；验证全部成功后才替换当前会话。文件载入错误会显示在侧栏，当前会话和自动存档保持原样。对应测试：`tests/store.test.ts`、`tests/ui.test.tsx`。

### 2. Phase 3 界面缺少自动化测试 · 已修复基础交互覆盖

~~原有测试只覆盖地图数据模型和坐标计算，React 界面、会话存储和 Three.js 地图生命周期没有交互测试。~~

修复：新增 DOM 交互测试，覆盖地图点选、阵营与镜头切换、机会裁定、文件载入错误和 WebGL 启动失败；新增存储测试和使用模拟 GPU 的地图生命周期测试。对应测试：`tests/ui.test.tsx`、`tests/store.test.ts`、`tests/tacticalMap.test.ts`。真实显卡上的画面、拾取精度及浏览器兼容性仍需浏览器端验收，模拟 GPU 测试不证明这些效果。

### 3. 数值边界缺少校验 · 已修复

~~交战通道可输入小数；数据文件中的速度、加速度、时延、库存、射程和概率界等参数缺少有效范围检查，后续修改参数可能产生无穷时间或非法状态。~~

修复：交战通道数必须是正整数；目录数据和想定的关键数值在载入时检查有限性、正负范围及整数要求；`SET_ROUTE` 检查坐标和速度为有限值。对应测试：`tests/intercept.test.ts`、`tests/data.test.ts`。

### 4. 长时间运行时的地图开销 · 待处理

地图的文字纹理缓存没有淘汰机制；航迹时龄会使标签文字持续变化。界面状态更新还会重新计算地图模型并多次重建场景。按本次约定，先保留现状，待长剧本出现实际性能问题后测量并处理。
